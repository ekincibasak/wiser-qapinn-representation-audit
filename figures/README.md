# Figures

## `results/`

These are scientific plots generated from experiment outputs: errors, robustness, spectral metrics, representation rank/CKA, and runtime.

## `conceptual/`

These are explanatory report graphics: the research question, benchmark rationale, architecture pathways, actual four-qubit circuit specification, graphical summary, and future-work roadmap.

Keeping these folders separate avoids confusing explanatory artwork with quantitative evidence.
